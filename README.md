# Quản lý Hạ tầng CNTT theo JCI phiên bản 8 – Bệnh viện

Giai đoạn 3 của hệ thống [Quản lý Trang thiết bị CNTT (BTH-ThietBiCNTT)](https://github.com/phuchaubth/BTH-ThietBiCNTT): bổ sung các chức năng giúp Phòng CNTT thực hiện và **chứng minh** việc tuân thủ tiêu chuẩn JCI phiên bản 8 đối với hạ tầng CNTT (chương MOI, FMS, GLD, QPS, SQE).

**Phạm vi:** chỉ hạ tầng CNTT – hệ thống thông tin (HIS, LIS, PACS, EMR…), máy chủ, lưu trữ, mạng, UPS và điều hoà phòng máy chủ. Không bao gồm thiết bị y tế.

## Phân hệ

| Mã | Phân hệ | Đợt |
|---|---|---|
| HTT | Danh mục hệ thống thông tin, mức trọng yếu, RTO/RPO, sơ đồ phụ thuộc | GĐ3.1 |
| DT | Kế hoạch downtime, sự kiện downtime, đào tạo, diễn tập | GĐ3.1 |
| SL | Sao lưu & thử phục hồi | GĐ3.1 |
| HD | Hành động khắc phục (CAPA) dùng chung | GĐ3.1 |
| RR | Đánh giá & quản lý rủi ro CNTT hằng năm | GĐ3.2 |
| JC | Báo cáo lãnh đạo, chỉ số, hồ sơ bằng chứng JCI | GĐ3.2 |
| TD | Quản lý thay đổi | GĐ3.3 |
| AN | Sự cố an ninh mạng | GĐ3.3 |
| TC | Rà soát quyền truy cập | GĐ3.3 |
